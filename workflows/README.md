# n8n workflows

Start with the English [workflow guide](../docs/WORKFLOW_GUIDE.md) and [independent reproduction guide](../docs/REPRODUCE_IT_YOURSELF.md).

- `wf-a` through `wf-d`: historical production capture, processing, report-delivery, and status exports.
- `wf-07…adapted.json` and `wf-08…adapted.json`: canonical adapted RC3.3 extraction/assistant artifacts, requiring your own credentials, database contracts, import, publication, and verification.
- Yuriy's original variants and companion workflows remain under `dashboard/reference-workflows/`.

These are reference artifacts, not an install bundle. Exported credential IDs/names are references only. Do not import all workflow families together or activate scheduled/email workflows against unfamiliar data.

The original R2 instructions are preserved in [history](../docs/history/WORKFLOWS_R2.md). Later RC3.1–3.3 records supersede specific R2 validation claims; they do not establish production acceptance.
